# Green Mart V4 — Website Demo

## About the Project
Green Mart V4 is a responsive grocery store website demo designed to showcase an easy and modern online shopping experience.

## Features
- Responsive desktop and mobile design
- Product search
- Product category filters
- Product sorting
- Shopping cart with quantity controls
- Automatic subtotal calculation
- Order enquiry form
- Downloadable order summary

## How to Run
1. Download or copy the project files.
2. Locate the `index.html` file.
3. Double-click `index.html` to open it in a web browser.
4. Browse products, add items to the cart, and test the checkout enquiry form.

No installation is required for the current demo.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Customization
Before the website goes live, replace the sample product names, prices, branding, address, phone number, and business information with verified details from the store.

## Important Notes
This is a demonstration website. The order enquiry form downloads a text summary but does not send orders to the store or process payments. Live ordering, payment processing, and inventory management require additional integration.
